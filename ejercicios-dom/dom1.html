  • Item 2

HTML completo (copia y pega)
<!-- Ejemplo 14: Agregar elementos a una lista --> <!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8" /> <meta name="viewport" content="width=device-width, initial-scale=1.0" /> <title>Ejemplo 14</title> </head> <body> <input type="text" id="inputItemLista" placeholder="Nuevo ítem..." /> <button id="btnAgregarItemLista">Agregar</button> <ul id="listaItems" style="list-style:none; padding-left:0;"> <li style="display:flex; justify-content:space-between; padding:0.2rem 0.3rem; border-bottom:1px solid #e8ecf0;">Item 1</li> <li style="display:flex; justify-content:space-between; padding:0.2rem 0.3rem; border-bottom:1px solid #e8ecf0;">Item 2</li> </ul> <script> document.getElementById('btnAgregarItemLista').addEventListener('click', function() { let input = document.getElementById('inputItemLista'); let texto = input.value.trim(); if (texto) { let li = document.createElement('li'); li.textContent = texto; li.style.display = 'flex'; li.style.justifyContent = 'space-between'; li.style.padding = '0.2rem 0.3rem'; li.style.borderBottom = '1px solid #e8ecf0'; document.getElementById('listaItems').appendChild(li); input.value = ''; } }); </script> </body> </html>

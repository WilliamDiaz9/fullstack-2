en esta versión lo que hicimos fue armar toda la estructura en html, entre axel
y alexis. son las 11 vistas de la tienda: home, login, registro, nosotros,
blogs (con sus 2 detalles), productos, detalle de producto, carrito y
contacto. usamos las etiquetas de html5 que corresponden (header, nav, main,
section, article, footer) y bootstrap desde cdn para no tener que maquetar
todo a mano.

todavía no le pusimos css propio ni javascript, por eso se ve con el estilo
por defecto de bootstrap no más. lo único que le dejamos andando fue la barra
de arriba con un color de fondo y el logo con tamaño fijo, directo en el html
con style, pa que no quedara todo montado encima del contenido.

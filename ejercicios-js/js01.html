JavaScript

Introducción al entorno
Conceptos
  • JavaScript: lenguaje interpretado, orientado a objetos, multiplataforma. Nació en 1995.
  • Frontend: se ejecuta en el navegador. Manipula DOM, eventos, peticiones HTTP, animaciones.
  • Backend: con Node.js, se ejecuta en servidor. APIs, bases de datos, autenticación.
  • Mobile: con React Native, Ionic, NativeScript (apps híbridas/nativas).
  • Motor JS: programa que lee y ejecuta el código. Cada navegador tiene el suyo: V8 (Chrome), SpiderMonkey (Firefox), JavaScriptCore (Safari).
Ejemplos
  • DevTools: F12 → Consola. Ejecutar console.log("Hola") en vivo.
  • VS Code: editor con extensiones (ESLint, Prettier, Live Server).
  • Etiqueta <script>:
    • Interno: <script> console.log("Hola"); </script>
    • Externo: <script src="app.js"></script>
<!-- Ejemplo completo -->
<!DOCTYPE html>
<html>
<head>
  <script src="analytics.js"></script>
</head>
<body>
  <h1>Mi página</h1>
  <script src="app.js"></script>
</body>
</html>
Ejercicios
  • Abrir la consola del navegador y escribir console.log("Mi primer script").
  • Crear un archivo HTML con un script interno que muestre un mensaje en la consola.
  • Crear un archivo JS externo y enlazarlo con <script src="...">.
Soluciones
<!-- archivo: index.html -->
<!DOCTYPE html>
<html>
<body>
  <script>
    console.log("Mi primer script");
  </script>
  <script src="mi-script.js"></script>
</body>
</html>

// archivo: mi-script.js
console.log("Desde archivo externo");
Módulo 1 Variables y tipos de datos
Conceptos
  • let, const, var
  • Tipos: string, number, boolean
  • undefined y null
  • Operador typeof
Ejemplos
let nombre = "Ana";
const edad = 28;
let esProfesor = false;

Ejercicios
  • Declarar variables: tu nombre, edad, y si eres estudiante.
  • Mostrar el tipo de cada una con typeof.
  • Convertir la edad a string y mostrarla.

let nombre = "Carlos";
let edad = 32;
let esEstudiante = true;

console.log(typeof edad);

Módulo 2 Operadores y expresiones
Conceptos
  • Aritméticos: + - * / % **
  • Asignación: = += -= *= /=
  • Comparación: === vs ==
  • Lógicos: && || !
  • Ternario: cond ? val1 : val2
Ejemplos
let a = 10, b = 3;
console.log(a % b); // 1
console.log(a === "10"); // false
let mensaje = (a > 5) ? "Mayor" : "Menor";
Ejercicios
  • Dado un número, determinar si es par o impar con operador ternario.
  • Verificar si un número es positivo y mayor que 100.
Soluciones
let num = 7;
let resultado = (num % 2 === 0) ? "Par" : "Impar";
console.log(resultado);

let x = 150;
console.log(x > 0 && x > 100); // true
Módulo 3 Condicionales (if, else, switch)
Conceptos
  • if / else if / else
  • switch (casos múltiples)
  • Evitar anidaciones excesivas
Ejemplos
let nota = 85;
if (nota >= 90) console.log("A");
else if (nota >= 80) console.log("B");
else console.log("C");
Ejercicios
  • Calificación: nota ≥90 → A, ≥80 → B, ≥70 → C, else → D.
  • Simular semáforo: "rojo" → "Alto", "verde" → "Siga", etc.
Soluciones
let nota = 75;
if (nota >= 90) console.log("A");
else if (nota >= 80) console.log("B");
else if (nota >= 70) console.log("C");
else console.log("D");

let color = "verde";
switch(color) {
  case "rojo": console.log("Alto"); break;
  case "verde": console.log("Siga"); break;
  default: console.log("Precaución");
}
Módulo 4 Bucles (while, do…while, for)
Conceptos
  • while y do...while
  • for (inicio; condición; incremento)
  • for...of (arrays/strings)
  • break y continue
Ejemplos
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// 1 2 3 4 5
Ejercicios
  • FizzBuzz: del 1 al 100, múltiplos de 3 → "Fizz", de 5 → "Buzz".
  • Tabla de multiplicar del 7 (del 1 al 10).
Soluciones
for (let i = 1; i <= 100; i++) {
  if (i % 3 === 0 && i % 5 === 0) console.log("FizzBuzz");
  else if (i % 3 === 0) console.log("Fizz");
  else if (i % 5 === 0) console.log("Buzz");
  else console.log(i);
}

for (let i = 1; i <= 10; i++) {
  console.log(7 * i);
}
Módulo 5 Funciones (parte 1)
Conceptos
  • Declaración function nombre() { }
  • Parámetros y argumentos
  • return (valor de retorno)
  • Ámbito local vs global
Ejemplos
function sumar(a, b) {
  return a + b;
}
console.log(sumar(5, 3)); // 8
Ejercicios
  • Función que calcule el área de un rectángulo (base × altura).
  • Función que convierta Celsius a Fahrenheit.
Soluciones
function areaRect(base, altura) {
  return base * altura;
}

function celsiusAFahrenheit(c) {
  return c * 9/5 + 32;
}
console.log(celsiusAFahrenheit(25)); // 77
Módulo 6 Arrays (vectores)
Conceptos
  • Creación: let arr = [1,2,3]
  • Propiedad length
  • Métodos: push/pop, unshift/shift
  • indexOf, includes, join
Ejemplos
let frutas = ["manzana", "pera"];
frutas.push("naranja");
console.log(frutas.length); // 3
console.log(frutas.join(" - "));
Ejercicios
  • Dado un array de nombres, mostrar solo los que empiezan con "A".
  • Eliminar el último elemento y mostrar el array.
Soluciones
let nombres = ["Ana", "Luis", "Andrés", "Marta"];
for (let n of nombres) {
  if (n[0] === "A") console.log(n);
}

nombres.pop();
console.log(nombres);
Módulo 7 Objetos literales
Conceptos
  • Sintaxis { clave: valor }
  • Acceso: obj.prop o obj["prop"]
  • Añadir / modificar / eliminar
  • Métodos (funciones dentro del objeto)
Ejemplos
let coche = {
  marca: "Toyota",
  modelo: "Corolla",
  descripcion() {
    return this.marca + " " + this.modelo;
  }
};
console.log(coche.descripcion());
Ejercicios
  • Crear objeto "cuenta" con saldo, y métodos depositar/retirar.
  • Recorrer el objeto con for...in.
Soluciones
let cuenta = {
  saldo: 100,
  depositar(cant) { this.saldo += cant; },
  retirar(cant) { if (cant <= this.saldo) this.saldo -= cant; }
};
cuenta.depositar(50);
console.log(cuenta.saldo); // 150
Módulo 8 Strings y métodos útiles
Conceptos
  • length, toUpperCase(), toLowerCase()
  • trim(), slice(), substring()
  • replace(), replaceAll()
  • Template literals: ${variable}
Ejemplos
let saludo = "  Hola Mundo  ";
console.log(saludo.trim()); // "Hola Mundo"
console.log(saludo.slice(0, 4)); // "Hol"
Ejercicios
  • Validar que un email contenga "@" y termine en ".com".
  • Mostrar nombre en mayúsculas con template literal.
Soluciones
let email = "usuario@correo.com";
let esValido = email.includes("@") && email.endsWith(".com");
console.log(esValido);

let nombre = "Laura";
console.log(`Hola ${nombre.toUpperCase()}`);

const saludar = (nombre) => console.log("Hola " + nombre);

Ejercicios

  • Usar una arrow function para sumar dos números.
Soluciones

  console.log(new Date().toLocaleTimeString());
}, 1000);

const sumar = (a, b) => a + b;
console.log(sumar(4, 6)); // 10

Bootstrap framework CSS

Que es Bootstrap

Bootstrap es un framework de codigo abierto creado por Twitter en 2011. Es una coleccion de herramientas CSS y JavaScript que nos permite construir paginas web de forma rapida y consistente.

Componentes listos Diseño responsivo Sistema de grid Clases predefinidas
  • No reinventar la rueda: Usa estilos y componentes ya creados.
  • Mobile-first: Diseñado para funcionar en cualquier dispositivo.
  • Basado en clases: Aplicas estilos usando clases HTML como btn, container, row.
  • Se integra con CSS: Puedes combinar Bootstrap con tu propio CSS.

Instalacion como usar Bootstrap

Estructura basica de una pagina con Bootstrap

Para usar Bootstrap, solo necesitas agregar una linea de CSS en el <head> de tu pagina. Aqui tienes la estructura basica:

<!-- Estructura basica de una pagina con Bootstrap -->
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Mi pagina con Bootstrap</title>
  <!-- Bootstrap CSS (siempre en el head) -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous" />
</head>
<body>
  <!-- Contenido de la pagina -->
  <div class="container">
    <h1>Hola Bootstrap</h1>
    <button class="btn btn-primary">Boton</button>
  </div>
</body>
</html>

CDN (Recomendado para empezar)

Usa la CDN (Content Delivery Network) para cargar Bootstrap desde un servidor externo.

CSS (siempre en el head):

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous" />

JavaScript (opcional, al final del body):

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" integrity="sha384-Zv+xi74fVgPRs3jfSkFqLAHxMqVQ5n3Fnn2r8pJQYgC1EMHh2iFeJpcCn93Yjz3Fp" crossorigin="anonymous"></script>

✓ No necesita descargar nada
✓ Siempre actualizado
✓ Ideal para proyectos pequeños

Sobre el CSS y JavaScript de Bootstrap

CSS (siempre obligatorio): El archivo CSS de Bootstrap contiene todos los estilos necesarios para que los componentes funcionen (botones, tarjetas, grid, etc.). Debe incluirse en el <head> para que los estilos se carguen antes de que el navegador renderice el contenido.

JavaScript (opcional): El JavaScript de Bootstrap es necesario solo para componentes interactivos como modales, carruseles, menús desplegables, etc. Se incluye al final del <body> para no bloquear la carga del contenido visible. Si tu pagina solo usa botones, tarjetas y grid (componentes estaticos), no necesitas el JavaScript.

Recomendacion: Para empezar, usa la version CDN. Es la manera mas rapida y sencilla de probar Bootstrap.

Ejercicios para practicar

Ejercicio 1

Enunciado: Crea una tarjeta (card) de Bootstrap que contenga:

- Un titulo que diga "Mi primera tarjeta"
- Un texto que diga "Este es el contenido de mi tarjeta"
- Un boton con estilo "warning" (amarillo) que diga "Haz clic"

Pista: Usa btn-warning para el boton.

Ver solucion
<!-- Solucion -->
<div class="card" style="width: 300px;">
  <div class="card-body">
    <h5 class="card-title">Mi primera tarjeta</h5>
    <p class="card-text">Este es el contenido de mi tarjeta</p>
    <button class="btn btn-warning">Haz clic</button>
  </div>
</div>

/* Resultado: Una tarjeta con titulo, texto y boton amarillo */

Ejercicio 2

Enunciado: Crea un grid de Bootstrap con 3 columnas iguales que contengan:

- Columna 1: texto "Producto 1" con fondo azul (bg-primary)
- Columna 2: texto "Producto 2" con fondo verde (bg-success)
- Columna 3: texto "Producto 3" con fondo rojo (bg-danger)

Pista: Usa row, col-4 y las clases bg-*.

Ver solucion
<!-- Solucion -->
<div class="row">
  <div class="col-4 bg-primary text-white p-3">
    Producto 1
  </div>
  <div class="col-4 bg-success text-white p-3">
    Producto 2
  </div>
  <div class="col-4 bg-danger text-white p-3">
    Producto 3
  </div>
</div>

/* Nota: text-white hace el texto blanco, p-3 es padding de 1rem */

Ejercicio 3

Enunciado: Crea un conjunto de 4 botones con los siguientes estilos:

- "Guardar" con estilo btn-success
- "Editar" con estilo btn-warning
- "Eliminar" con estilo btn-danger
- "Cancelar" con estilo btn-secondary

Los botones deben estar en una fila horizontal con separacion entre ellos.

Ver solucion
<!-- Solucion -->
<div class="d-flex gap-2">
  <button class="btn btn-success">Guardar</button>
  <button class="btn btn-warning">Editar</button>
  <button class="btn btn-danger">Eliminar</button>
  <button class="btn btn-secondary">Cancelar</button>
</div>

/* Nota: d-flex gap-2 hace que los botones esten en fila con separacion */

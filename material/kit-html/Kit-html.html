KIT HTML - Etiquetas basicas

Estructura basica DOCTYPE + HTML + HEAD + BODY
Descripcion: La estructura fundamental de cualquier documento HTML.
<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <title>Mi Pagina</title> </head> <body> <h1>Hola Mundo!</h1> <p>Mi primera pagina web</p> </body> </html>

Titulos (H1 - H6) h1 · h2 · h3 · h4 · h5 · h6
Descripcion: Los titulos definen la jerarquia de contenido. <h1> es el mas importante, <h6> el menos.
<h1>Titulo nivel 1</h1> <h2>Titulo nivel 2</h2> <h3>Titulo nivel 3</h3> <h4>Titulo nivel 4</h4> <h5>Titulo nivel 5</h5> <h6>Titulo nivel 6</h6>

Parrafos y formato de texto p · br · strong · em · u · mark
Descripcion: Elementos para estructurar y dar formato al texto.
<p>Este es un parrafo normal.</p> <p>Este es otro parrafo con <br> salto de linea.</p> <p>Texto <strong>negrita</strong>, <em>cursiva</em>, <u>subrayado</u>, <mark>resaltado</mark></p>

Listas ul · ol · li
Descripcion: Listas ordenadas (numeradas) y no ordenadas (con viñetas).
<ul> <li>Elemento 1</li> <li>Elemento 2</li> <li>Elemento 3</li> </ul> <ol> <li>Primero</li> <li>Segundo</li> <li>Tercero</li> </ol>

  • Elemento 2
  • Elemento 3
  1. Primero
  2. Segundo

Enlaces (Links) a · href · target
Descripcion: El elemento <a> crea hipervinculos a otras paginas o secciones.
<!-- Enlace a pagina externa --> <a href="https://www.ejemplo.com"> Visitar Ejemplo </a> <!-- Enlace que abre en nueva pestaña --> <a href="https://www.google.com" target="_blank"> Google (nueva pestaña) </a> <!-- Enlace a seccion interna --> <a href="#seccion">Ir a seccion</a>

Imagenes img · src · alt · width · height
Descripcion: La etiqueta <img> inserta imagenes en la pagina. alt es importante para accesibilidad.
<!-- Imagen con texto alternativo --> <img src="https://picsum.photos/200/150" alt="Imagen de ejemplo"> <!-- Imagen con tamano definido --> <img src="https://picsum.photos/200/150" alt="Imagen pequena" width="150" height="100">

Tablas table · tr · th · td · thead · tbody
Descripcion: Las tablas organizan datos en filas y columnas.
<table> <thead> <tr> <th>Nombre</th> <th>Edad</th> <th>Ciudad</th> </tr> </thead> <tbody> <tr> <td>Ana</td> <td>25</td> <td>Madrid</td> </tr> <tr> <td>Luis</td> <td>30</td> <td>Barcelona</td> </tr> </tbody> </table>

Contenedores: DIV y SPAN div · span
Descripcion: <div> es un contenedor de bloque, <span> es un contenedor en linea. Se usan para agrupar y estilizar.
<!-- DIV (bloque) --> <div class="box-demo"> Esto es un DIV - elemento de bloque </div> <!-- SPAN (en linea) --> <p>Texto con <span style="color: red;"> texto en rojo</span> dentro del parrafo. </p> <!-- Varios DIV --> <div class="box-demo blue">Azul</div> <div class="box-demo green">Verde</div>

Formularios basicos form · input · label · button
Descripcion: Los formularios permiten recoger datos del usuario.
<form> <label for="nombre">Nombre:</label> <input type="text" id="nombre" placeholder="Ingresa tu nombre"> <br><br> <label for="email">Email:</label> <input type="email" id="email" placeholder="ejemplo@mail.com"> <br><br> <label for="password">Password:</label> <input type="password" id="password"> <br><br> <button type="submit">Enviar</button> </form>






Botones button
Descripcion: El elemento <button> crea botones interactivos.
<!-- Boton normal --> <button>Click aqui</button> <!-- Botones con estilos basicos --> <button style="background: #2c5f2c; color: white; padding: 8px 16px; border: none;"> Verde </button> <button style="background: #b22222; color: white; padding: 8px 16px; border: none;"> Rojo </button> <button style="background: #3d3d3d; color: white; padding: 8px 16px; border: none;"> Negro </button>
